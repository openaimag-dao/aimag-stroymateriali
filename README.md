# AIMAG Stroymateriali

Оптовый интернет-магазин стройматериалов для ТОО и ИП Казахстана: оптовые цены с НДС после входа, КП и счёт за минуты, загрузка спецификаций, доставка по РК.

Стек: Next.js 15 (App Router) · React 18 · Tailwind · Supabase (Postgres, Auth, Storage) · Vercel. Цвета и шрифты — как у aimag-electric.

## Что уже есть

| Раздел | Путь | Состояние |
| --- | --- | --- |
| Главная | `/` | готово |
| Каталог и категории, поиск | `/catalog`, `/catalog/[slug]`, `/catalog?q=` | разделы и подразделы, фильтры по характеристикам, карточка группы с выбором варианта; структура видна всем, цены — после входа |
| Корзина | `/cart` | в браузере (localStorage), итоги с НДС 16%; кнопки «Выставить счёт» и «Получить КП» |
| КП и счёт | `/account/quotes/[id]`, `/api/documents/quote/[id]`, `/api/documents/invoice/[id]` | цены считает база (`create_quote`), счёт — `issue_invoice`; PDF в фирменном стиле |
| Вход по email | `/login`, `/auth/callback` | Supabase magic link |
| Регистрация компании по БИН | `/account` | проверка контрольной цифры БИН/ИИН, RPC `register_company` |
| Кабинет: КП и счета | `/account` | список КП своей компании со статусом счёта |
| Загрузка спецификации | `/spec` | файл в Storage `specs/<company_id>/`, строка в `specs` |

Дальше: админка (импорт прайсов, наценки, курс, реквизиты и печать продавца, доставка в КП), автозаполнение реквизитов по БИН, разбор спецификаций ИИ.

## База

Миграции в `supabase/migrations/` применяются по порядку (`0001` … `0005`).

- Одна цена товара — `products.price_kzt` (с НДС); в КП и счёт она копируется снимком, поэтому в разных документах не расходится.
- Покупатель видит только данные своей компании (RLS). Компанию правит только персонал (`staff`), чтобы покупатель не мог поменять себе скидку.
- Повторная регистрация уже существующего БИН запрещена: сотрудников добавляет владелец или менеджер.
- Продавцы в документах: ИП AIMAG и ЖК Bereke (`sellers`). Банковские реквизиты (ИИК, БИК, банк, Кбе) и ссылки на печать и подпись вносятся в базу, **не в код** — репозиторий публичный. Пока у продавца нет ИИК, счёт автоматически не выставляется (КП — выставляется).
- Номера: КП — `КП-ГГММДД-NN`, счёт — `ГГММДД-NN`, счётчик на день по времени Алматы. КП действует 7 календарных дней.
- Цена в КП = лучшая из оптовых цен по объёму, минус персональная скидка компании; цена из браузера не используется.
- Варианты товара: каждый вариант (толщина × покрытие × цвет, диаметр × PN, тип фитинга × диаметр × резьба) — отдельная строка `products` со своей ценой; варианты объединены в `product_groups`, характеристики — в `product_attributes` (значения только из справочника `attribute_options`). Какие характеристики фильтруют и выбираются в подразделе — `category_attributes`.
- Разделы с подразделами: Кровля (металлочерепица, профнастил, доборные, водосток, мембраны, крепёж), Фасад (сайдинг и комплектующие, фасадные панели, подсистема вентфасада, ветро- и влагозащита), Сантехника и трубы (PP-R, ПНД и фитинги, канализация, запорная арматура).

Вид карточек и фильтров на демо-данных без базы: `npm run dev` → `/dev/catalog-preview` (в продакшене страницы нет).
